# IEPROES · Apps

Página principal de las apps del personal de IEPROES (Centro Regional San Miguel).
Publicada en https://admi-gr.github.io/ieproes/

- El catálogo sale de `public.apps` del proyecto Supabase "IEPROES Apps" (separado de ADMI).
- Cuentas solo por invitación: un administrador invita desde la sección **Accesos**
  (Edge Function `invitar`) y ahí mismo asigna rol y acceso a cada app.
- Probar en local: `npx http-server . -p 3000` y abrir http://localhost:3000
